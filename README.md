# DNA-Sequence-Analyzer
A Python-based bioinformatics tool for basic DNA sequence analysis, transcription, and translation.

## Overview

This project applies Python programming concepts to molecular biology
by providing a simple tool for analysing DNA sequences.

## Features

- DNA validation
- Input cleaning
- Nucleotide counting
- GC-content calculation
- Complementary DNA generation
- DNA-to-RNA transcription
- RNA codon extraction
- RNA-to-protein translation

## Example

Input:

ATGGCTTACTAA

The program analyses the sequence and reports nucleotide composition,
GC content, complementary DNA, RNA transcription and predicted protein
translation.

## Technologies

- Python 3
- Google Colab

## Biological Concepts

- DNA base pairing
- Transcription
- Codons
- Translation
- Genetic code

## Limitations

This is an educational project and does not represent a complete
biological sequence-analysis pipeline.

Future development will focus on applying these computational skills
to real biological datasets.
